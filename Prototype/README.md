# ToneBridge prototype (laptop reference pipeline)

VI -> EN speech-to-speech, all stages real, all local. Models live under `models/` (git-ignored); the complete list of files the pipeline reads is `docs/OFFLINE_FILES.md`.

## Run one utterance (`--full`, 0 stubs)

From `Prototype/`, Windows PowerShell:

```powershell
$env:PYTHONPATH = "src"
.venv\Scripts\python.exe -m tonebridge.cli --wav models\asr\zipformer-vi-int8\test_wavs\0.wav --out out.wav --full --assert-offline --log results\turns.jsonl
```

`--assert-offline` blocks and counts network use during the run and adds `offline_audit` to the JSONL row: `net_attempts_python` (socket calls attempted, each one is refused) and
`net_conns_os_seen` (connections seen in the OS table, sampled every 20 ms). Expected: both 0. It also sets `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`.

## Manual offline check (wifi off)

1. Turn Wi-Fi off and unplug Ethernet (`Get-NetAdapter | Where Status -eq Up` should list nothing but loopback/virtual adapters).
2. Run exactly this, from `Prototype/`:

```powershell
$env:PYTHONPATH = "src"; $env:HF_HUB_OFFLINE = "1"; $env:TRANSFORMERS_OFFLINE = "1"
Remove-Item results\manual_offline.jsonl -ErrorAction SilentlyContinue
foreach ($i in 0,1,2) {
  .venv\Scripts\python.exe -m tonebridge.cli --wav "models\asr\zipformer-vi-int8\test_wavs\$i.wav" --out "out_$i.wav" --full --assert-offline --log results\manual_offline.jsonl
}
.venv\Scripts\python.exe -c "import json; r=[json.loads(l) for l in open('results/manual_offline.jsonl', encoding='utf8')]; print(len(r), 'rows;', 'OFFLINE OK' if all(x['offline_audit']['net_attempts_python']==0 and x['offline_audit']['net_conns_os_seen']==0 for x in r) else 'NETWORK SEEN')"
```

Pass = three `out_*.wav` files, three JSONL rows, every row has `net_attempts_python: 0` and `net_conns_os_seen: 0`.

## Automated checks

```powershell
.venv\Scripts\python.exe -m pytest tests\test_offline.py -q     # sockets blocked, library caches redirected to empty dirs, 3 wavs through --full
.venv\Scripts\python.exe tools\offline_audit.py manifest          # regenerates docs\OFFLINE_FILES.md + configs\runtime_files.json (sha256)
.venv\Scripts\python.exe tools\offline_audit.py trace models\asr\zipformer-vi-int8\test_wavs\0.wav   # data files opened/mapped outside the project (expect none)
.venv\Scripts\python.exe tools\offline_audit.py clone C:\tmp\tb_clone   # fresh git clone + ONLY the manifest model files; then run the CLI from C:\tmp\tb_clone\Prototype with PYTHONPATH=src
```
